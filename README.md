Electricity Demand Forecasting using LSTM ⚡
Overview

Electricity demand forecasting is an important task in power system management. Accurate prediction of electricity consumption helps grid operators maintain supply-demand balance, reduce operational costs, and improve energy distribution planning.

This project implements a machine learning based electricity demand forecasting system using a Long Short-Term Memory (LSTM) neural network trained on historical electricity consumption data from the PJM Interconnection dataset. The system predicts electricity demand and provides interactive visualizations through a Streamlit web dashboard.

Features

Short-term electricity demand prediction

LSTM-based time series forecasting

Interactive Streamlit dashboard

24-hour demand forecast visualization

Typical daily demand pattern analysis

Weekday vs weekend demand comparison

Electricity demand heatmap visualization
